# PrintLab
Текущий объём: Sprint 3 — учётные записи, каталог, конструктор одежды и корзина. Заказы, оплата и администрирование остаются будущими спринтами и не реализуются без отдельного задания. Схему PostgreSQL изменять только новыми миграциями Flyway. Секреты не коммитить.

Локальные определения ролей пользователя: `%USERPROFILE%\Projects\PrintLab\.codex\agents`. При запросе ролей проверять файлы и возможности текущей сессии; наличие файлов само по себе не подтверждает автоматическую загрузку.

На всех страницах сохранять минималистичный стиль PrintLab из docs/DESIGN_SYSTEM.md. Не удалять существующие блоки и функции без явного запроса пользователя.
