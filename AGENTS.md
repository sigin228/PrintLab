# PrintLab
Текущий объём: спринты 1 и 2 — аккаунт, профиль и каталог. Следующие функции не начинать без нового задания: корзина, принты, заказы, промокоды, платежи и админка. Не создавать таблицы будущих спринтов. Схему БД изменять только новыми миграциями Flyway; применённые миграции не редактировать. Секреты не коммитить.

Локальные определения ролей пользователя находятся в `%USERPROFILE%\Projects\PrintLab\.codex\agents` (ui_designer, frontend_developer, database_architect, qa_reviewer). При запросе этих ролей проверь файлы и возможности текущей сессии; наличие файлов само по себе не подтверждает автоматическую загрузку. Не переносить и не изменять их без необходимости.
