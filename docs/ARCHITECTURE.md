# Архитектура

Учебный монолит Java 21 и Spring Boot: браузер → Controller → Service → PostgreSQL через JPA и JdbcTemplate. Thymeleaf формирует HTML, JavaScript и Konva.js управляют редактором. Spring Security отвечает за сессии и права, Flyway — за миграции. Заказ хранит снимки дизайна, сервер рассчитывает суммы и резервирует остатки. Демо-оплата записывает виртуальный баланс и журнал транзакционно. Бинарные файлы хранятся отдельно от БД.
