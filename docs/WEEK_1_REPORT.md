# Отчёт о первой неделе

Реализованы открытая главная страница, регистрация, вход, защищённый профиль, редактирование профиля и выход. Согласованное исключение: заранее созданы только таблицы каталога products и product_variants; функции каталога отложены до следующего задания.

PostgreSQL 17.12: база printlab_db, пользователь printlab_app; миграции Flyway V1 и V2 применены, присутствуют четыре прикладные таблицы и служебная flyway_schema_history. Hibernate проверяет структуру.

Проверка: `mvnw.cmd -B -ntp clean verify` — BUILD SUCCESS, один интеграционный тест прошёл на PostgreSQL: регистрация, уникальность email, проверка паролей, BCrypt, профиль, CSRF, вход и выход. В браузере проверены главная, регистрация, вход, сохранение профиля и выход; созданная для браузерной проверки тестовая запись удалена. Конкурентная регистрация отдельно нагрузочным тестом не проверена; защита основана на UNIQUE и обработке ошибки БД.

Среда: JDK 21 и PostgreSQL уже имелись; ничего не устанавливалось. При запуске из Codex на Windows понадобился `-Djdk.net.unixdomain.tmpdir=C:\Windows\Temp`; он добавлен только в исключённый из Git локальный скрипт. Проверены java, javac через JDK, Git, Node.js, PostgreSQL и Maven Wrapper. npm и gh не найдены в PATH. Публичный GitHub-репозиторий пока не создан: требуется вход пользователя.
