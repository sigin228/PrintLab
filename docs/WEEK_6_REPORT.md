# Sprint 6 — администрирование

Добавлены панель ADMIN, управление товарами, вариантами, заказами и статусами, статистика, административные принты и форма письма покупателю. Почта требует настройки; фактическая доставка не проверена. Локальные данные администратора находятся вне Git в `local/printlab-admin-access.txt`.

V8 добавляет учёт временных изображений, V9 — административные принты. Для изменения остатка предусмотрена проверка актуального значения. Код проходит интеграционную проверку; визуальная и сквозная проверка браузером не выполнены.
