# База данных

PostgreSQL изменяется новыми миграциями Flyway; применённые файлы не переписываются. `flyway_schema_history` — служебная таблица.

| Миграции | Таблицы и изменения |
| --- | --- |
| V1–V4 | users, user_profiles, products, product_variants; логин, город и демонстрационный каталог |
| V5 | designs, carts, cart_items |
| V6 | promo_codes, orders, order_items |
| V7 | demo_wallets, payments, wallet_transactions |
| V8 | design_uploads — учёт временных файлов |
| V9 | admin_print_presets — административные принты |

У пользователя один профиль и не более одной корзины; корзина содержит много позиций. Товар имеет варианты. У пользователя много дизайнов и заказов; заказ содержит позиции и может иметь промокод. У пользователя один демо-кошелёк с журналом операций. Возможны несколько попыток оплаты и не более одной успешной или возвращённой оплаты на заказ. PK, FK, UNIQUE и CHECK определены миграциями. Состояние дизайна хранится в JSONB, изображения — в файловом хранилище: резервируйте БД и файлы вместе.
