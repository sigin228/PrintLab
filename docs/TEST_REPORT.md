# Состояние проверки

- `mvnw.cmd -B -ntp clean verify` на отдельной PostgreSQL: **45 тестов прошли**, ошибок и пропусков нет. Проверены рендеринг страниц, регистрация, права администратора, оформление с промокодом, оплата, параллельная оплата, конкуренция за последний товар и промокод, гонка оплаты и отмены, очистка загрузок и сохранение снимков.
- На рабочей базе Flyway успешно применил V6–V9. Проверен HTTP-вход созданного локального администратора и ответы 200 для `/admin`, `/admin/products`, `/admin/prints`, `/admin/promos`, `/admin/orders`, `/wallet` и `/orders`. Заказы на рабочей базе в ходе проверки не создавались.
- Браузерный инструмент отказал в открытии вкладки по политике безопасности. Скриншоты, мобильная адаптивность, жесты и полный путь покупателя текущей версии визуально не проверены.
- Фактическая отправка почты и полноценный аудит безопасности не выполнялись. Автоматические проверки не заменяют проверку редактора с мышью и пальцем.

Команда: `./mvnw.cmd clean verify` с отдельной тестовой базой. Обновляйте отчёт по фактическому результату.
