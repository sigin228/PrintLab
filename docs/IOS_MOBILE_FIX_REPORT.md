# Исправления мобильной версии и принтов

## Причина и исправление
При открытии сайта по HTTP через локальный IP браузер может не предоставлять crypto.randomUUID(): этот API требует защищённого контекста. В конструкторе это приводило к сообщению «Не удалось загрузить принт». Добавлен вариант генерации UUID через crypto.getRandomValues, работающий в таком контексте; при отсутствии безопасного генератора показывается ошибка. Защита CSRF и авторизация сохранены.

Добавлены адаптации элементов управления, размеров полей и зон нажатия для мобильных экранов, локальные SVG-иконки, поддержка reduced motion, запасной вариант при отсутствии ResizeObserver и совместимая с Safari проверка свойств объектов. Схема базы данных не изменялась.

## Проверки
- До исправления ошибка добавления готового принта воспроизведена в браузере на адресе локальной сети.
- `mvnw -o -B -ntp clean verify`: 50 тестов, ошибок нет. В том числе серверный сценарий сохранения дизайна и работы корзины с авторизацией и CSRF в изолированной тестовой БД.
- `node scripts/test-ios-uuid.cjs`: проверены randomUUID, getRandomValues и обработка отсутствия безопасного генератора.
- `node --check` для изменённых скриптов конструктора и превью корзины.
- Приложение после сборки запущено на порту 8080.

Повторная проверка интерфейса после исправления не завершена: браузерный инструмент заблокировал навигацию после того, как страница оказалась недоступна во время перезапуска приложения. На настоящем iPhone и в Safari исправления не проверялись; визуальная проверка контрольных размеров также не выполнена. Серверные тесты не заменяют проверку реального браузерного сценария.
