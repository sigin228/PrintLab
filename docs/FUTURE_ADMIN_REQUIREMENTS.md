# Пожелания к будущей административной панели

Запланировано после Sprint 3 по отдельному заданию: управление одеждой, вариантами цветов, изображениями, принтами и ценами; просмотр заказов. Администратор сможет составить сообщение в интерфейсе, которое будет отправлено на email, указанный клиентом. Двусторонняя переписка на сайте не требуется. Для реальной отправки позднее потребуются адрес отправителя, SMTP/почтовый сервис и его локальная конфигурация; секреты не размещать в репозитории. Данный документ описывает будущее требование, а не существующую функцию.
