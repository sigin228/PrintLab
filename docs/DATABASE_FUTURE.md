# План базы PrintLab

Источник: схема пользователя для шести недель. Flyway управляет изменениями; полную схему сразу не выполнять.

1. users — учётные записи; user_profiles — профиль, связь 1:1.
2. products — товары; product_variants — размеры, цвета, остатки (1:N). Таблицы созданы заранее в V2; каталог реализован во втором спринте, V4 добавляет демонстрационные данные.
3. designs — пользовательские принты; carts — корзины; cart_items — позиции корзин.
4. promo_codes — скидки; orders — заказы; order_items — снимки позиций заказа.
5. demo_wallets — демонстрационные кошельки; payments — демонстрационные платежи; wallet_transactions — операции кошелька.
6. Новые таблицы не предусмотрены.

Оплата исключительно демонстрационная. Для будущих таблиц действуют поля и связи из предоставленной пользователем схемы; окончательные ограничения уточняются в соответствующем спринте.
