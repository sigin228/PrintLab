# PrintLab

Учебный магазин: на текущем этапе доступны главная страница, регистрация, вход и профиль. Таблицы каталога подготовлены, функции каталога появятся позднее.

## Запуск в Windows

Нужны JDK 21 и PostgreSQL 17. Создайте базу и пользователя с правом изменять её схему, затем задайте переменные PRINTLAB_DB_URL, PRINTLAB_DB_USER и PRINTLAB_DB_PASSWORD по примеру .env.example (файл .env автоматически не загружается). Запустите: .\mvnw.cmd spring-boot:run.

На этом компьютере доступен локальный скрипт local/run.ps1, содержащий пароль; он исключён из Git. В PowerShell его можно запустить командой .\local\run.ps1. Сайт: http://localhost:8080.

Тесты используют указанную PostgreSQL: .\mvnw.cmd clean verify. Flyway применяет миграции автоматически; Hibernate только проверяет схему. Не запускайте тесты на базе с важными данными без отдельной настройки.

При регистрации укажите логин, имя, город, email и пароль. Вход выполняется по логину или email; город доступен для изменения в профиле.
