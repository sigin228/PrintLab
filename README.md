# PrintLab

Учебное Spring Boot приложение: открытый каталог одежды, поиск и фильтр, карточки товаров, регистрация, вход и личный кабинет. Каталог доступен гостям; покупки и корзина пока не реализованы. Данные и изображения товаров демонстрационные.

## Запуск в Windows

Нужны JDK 21 и PostgreSQL 17. Создайте базу и пользователя с правом изменять её схему, затем задайте переменные `PRINTLAB_DB_URL`, `PRINTLAB_DB_USER` и `PRINTLAB_DB_PASSWORD` по примеру `.env.example` (сам файл .env не загружается автоматически). Запустите `.\mvnw.cmd spring-boot:run`.

На этом компьютере доступен локальный скрипт `local/run.ps1`, содержащий пароль и исключённый из Git: `.\local\run.ps1`. Сайт: http://localhost:8080; каталог: http://localhost:8080/catalog.

Тесты используют указанную PostgreSQL: `.\mvnw.cmd clean verify`. Flyway автоматически применяет миграции, включая однократное заполнение каталога; Hibernate проверяет схему. Не запускайте тесты на базе с важными данными без отдельной настройки. На некоторых компьютерах Codex под Windows для запуска может потребоваться настройка `JAVA_TOOL_OPTIONS=-Djdk.net.unixdomain.tmpdir=C:\Windows\Temp`.

При регистрации укажите логин, имя, город, email и пароль. Вход выполняется по логину или email; город доступен для изменения в профиле.

Дизайн-система описана в `docs/DESIGN_SYSTEM.md`, отчёты — в `docs/DESIGN_REPORT.md` и `docs/WEEK_2_REPORT.md`. Шрифт Manrope загружается через Google Fonts с системным запасным вариантом.
