# PrintLab

Учебное Spring Boot приложение: открытый каталог одежды, регистрация, вход, личный кабинет, конструктор принтов и корзина. Каталог и конструктор доступны гостям; сохранение дизайна и корзина требуют входа. Оформление заказа и оплата пока не реализованы. Данные и изображения товаров демонстрационные.

## Запуск в Windows

Нужны JDK 21 и PostgreSQL 17. Создайте базу и пользователя с правом изменять её схему, затем задайте переменные `PRINTLAB_DB_URL`, `PRINTLAB_DB_USER` и `PRINTLAB_DB_PASSWORD` по примеру `.env.example` (сам файл .env не загружается автоматически). Запустите `.\mvnw.cmd spring-boot:run`.

На этом компьютере доступен локальный скрипт `local/run.ps1`, содержащий пароль и исключённый из Git: `.\local\run.ps1`. Сайт: http://localhost:8080; каталог: http://localhost:8080/catalog.

Тесты используют указанную PostgreSQL: `.\mvnw.cmd clean verify`. Flyway автоматически применяет миграции, включая однократное заполнение каталога; Hibernate проверяет схему. Не запускайте тесты на базе с важными данными без отдельной настройки. На некоторых компьютерах Codex под Windows для запуска может потребоваться настройка `JAVA_TOOL_OPTIONS=-Djdk.net.unixdomain.tmpdir=C:\Windows\Temp`.

При регистрации укажите логин, имя, город, email и пароль. Вход выполняется по логину или email; город доступен для изменения в профиле.

В карточке товара откройте конструктор: выберите размер и цвет, добавьте текст или PNG/JPEG и настройте элементы на передней и задней стороне. Сохранённый дизайн можно добавить в корзину; непустой принт стоит 1 000 ₸ за дизайн. Расчёт и проверка остатков выполняются на сервере. При переходе гостя к входу несохранённый макет теряется. Чтобы изменить дизайн, уже находящийся в корзине, сначала удалите соответствующую позицию.

Загруженные изображения хранятся отдельно от базы в `local/uploads` (или каталоге из `PRINTLAB_UPLOAD_DIR`), который нужно включать в резервное копирование. Автоматическая очистка неиспользуемых загрузок пока не реализована: файлы могут накапливаться. Не публикуйте этот каталог и не добавляйте его в Git.

Дизайн-система описана в `docs/DESIGN_SYSTEM.md`, отчёты — в `docs/DESIGN_REPORT.md`, `docs/WEEK_2_REPORT.md` и `docs/WEEK_3_REPORT.md`. Шрифт Manrope загружается через Google Fonts с системным запасным вариантом.
