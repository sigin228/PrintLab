# PrintLab

Учебное приложение на Java и Spring Boot: каталог, регистрация, конструктор одежды, корзина, заказы, демо-кошелёк и административная панель. Все средства виртуальные; настоящие платежи и банковские реквизиты не используются. Товары и изображения демонстрационные.

## Запуск

Нужны JDK 21 и PostgreSQL. Создайте базу и пользователя с правом изменять схему. Установите переменные `PRINTLAB_DB_URL`, `PRINTLAB_DB_USER` и `PRINTLAB_DB_PASSWORD` по примеру `.env.example` (файл .env автоматически не загружается). Запустите `./mvnw.cmd spring-boot:run` в PowerShell. На этом компьютере доступен исключённый из Git скрипт `./local/run.ps1`. Сайт: http://localhost:8080.

Локальные данные администратора хранятся в `local/printlab-admin-access.txt`; не публикуйте этот файл. Панель доступна по адресу `/admin`.

При регистрации укажите логин, имя, город, email и пароль; вход возможен по логину или email. Гость может открыть каталог и редактор, а сохранение и корзина требуют входа. Добавьте текст или изображение, сохраните дизайн, выберите вариант и добавьте вещь в корзину. Оформленный заказ можно оплатить демонстрационными средствами, не имеющими денежной ценности.

Почта администратора необязательна. Для SMTP используйте переменные Spring Boot `SPRING_MAIL_HOST`, `SPRING_MAIL_PORT`, `SPRING_MAIL_USERNAME`, `SPRING_MAIL_PASSWORD` и `PRINTLAB_MAIL_FROM`. Не добавляйте секреты в Git. Реальная доставка писем не проверена.

Изображения пользователей хранятся отдельно от БД в `PRINTLAB_UPLOAD_DIR` (по умолчанию `local/uploads`). Резервируйте базу и файлы вместе. Для тестов используйте отдельную PostgreSQL и команду `./mvnw.cmd clean verify`. Flyway применяет миграции V1–V9; Hibernate проверяет схему.

Архитектура описана в [ARCHITECTURE](docs/ARCHITECTURE.md), маршруты — в [API_AND_ROUTES](docs/API_AND_ROUTES.md), состояние проверок — в [TEST_REPORT](docs/TEST_REPORT.md). Визуальная браузерная проверка текущей версии пока не выполнена.
